# Heatmap demo vault

Run `pnpm dev` from the repository, open this folder as an Obsidian vault, and
enable **Heatmap Bases View** in **Settings → Community plugins**.

Open [[Habits.base|Habits]] to try a boolean exercise heatmap and a numeric mood
heatmap. The first view is a heatmap so it also exercises loading a Base with a
custom default view. Select a filled cell to open its daily note. January 4 has
no note, demonstrating the empty cell style.

The example covers January 2026. Edit notes in [[Daily Notes/2026-01-01]] or
change the view settings to try other values, colors, layouts, and cell sizes.
